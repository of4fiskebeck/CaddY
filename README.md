# CaddY

En humoristisk, Tesla-inspirert PWA for en ekte, manuell Volkswagen Caddy 2018. Ingen biltilkobling.

## Publisering med GitHub Pages

1. Opprett et offentlig repository, for eksempel `caddy`.
2. Last opp alle filene fra denne mappen til roten av repositoryet.
3. Gå til **Settings → Pages → Build and deployment**, velg **Deploy from a branch**, `main` og `/ (root)`.
4. Åpne Pages-adressen GitHub viser. På iPhone: Del → Legg til på Hjem-skjermen.

Skrittelleren er humorbasert som standard, med frivillig eksperimentell bruk av telefonens bevegelsessensor. Sensoren kan telle feil og krever tillatelse, HTTPS og at appen er åpen. Kalorier er grovt anslått til 0,04 kcal per skritt, ikke målt energiforbruk.

Viktig: Ikke la motoren gå i garasje eller lukkede rom. Følg lokale regler for tomgangskjøring.
