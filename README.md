# CaddY – Tesla-inspirert design

Ny versjon med mørk Tesla-inspirert layout og studioillustrasjon av Caddy.

Last opp filene i denne ZIP-filen direkte i roten av GitHub-repositoryet. Erstatt eksisterende filer med samme navn. `caddy-studio.png` må også lastes opp.

Dette er en humorapp og har ingen forbindelse til bilen.
